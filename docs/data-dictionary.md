# 数据字典与业务口径

## 分析粒度

预算表和实际表的唯一业务键为月份、事业部和产品。月份使用每月第一天表示，报表按月展示。

## 预算字段

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| budget_quantity | 预算销量 | 虚构业务单位 |
| budget_unit_price | 预算平均单价 | 人民币元每单位 |
| budget_unit_variable_cost | 预算单位变动成本 | 人民币元每单位 |
| budget_fixed_expense | 分配到产品层级的预算固定费用 | 人民币元 |

## 实际字段

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| actual_quantity | 实际销量 | 虚构业务单位 |
| actual_revenue | 实际确认收入 | 人民币元 |
| actual_variable_cost | 实际变动成本 | 人民币元 |
| actual_fixed_expense | 分配到产品层级的实际固定费用 | 人民币元 |

## 预测假设

谨慎、基准和乐观情景分别设置销量、价格、单位变动成本和固定费用系数。系数只应用于实际截止月份之后的预算值，已经发生月份始终使用实际数据。

## 差异归因顺序

收入差异先计算数量影响，再以实际数量计算价格影响，因此数量与价格的交互项归入价格影响。

利润差异先使用预算产品结构和预算单位边际贡献计算总销量影响，再计算实际结构偏离预算结构的影响，之后加入价格、单位成本和固定费用影响。五项影响之和必须与经营利润总差异一致。

## 有利与不利方向

利润影响为正表示有利，为负表示不利。成本或费用本身增加时，利润影响使用负数表示。百分比在预算金额为零时应视为不可用，而不是零。

## 数据安全

公开演示的事业部、产品、金额、价格、成本、销量和情景系数均由代码构造，不对应任何真实主体。项目不读取网络、数据库、环境变量或外部业务文件来生成默认 Demo。

## 输入标准化与拒绝规则

模型会把可转换的数字文本转成数值，并把日期统一到对应月份的第一天。空预算表、空实际表、无效日期、空事业部或产品、重复业务键、负数、非数字以及实际记录缺少对应预算时，模型会在计算前明确拒绝输入。
