# 项目实施计划

## 阶段一：数据契约与合成数据

- 定义预算、实际和预测假设表。
- 固定指标、期间、主键和正负号口径。
- 生成正常数据及可验证的异常样本。

状态：已完成第一版。已生成全年预算、已发生月份实际和三种预测假设，并实现字段、主键、数值范围与预算匹配校验。

## 阶段二：预算差异与归因

- 计算收入、毛利、经营利润的预算差异。
- 拆分价格、销量、产品结构、单位成本和固定费用影响。
- 建立总差异与各项归因的勾稽测试。

状态：已完成。利润桥已将总销量、产品结构、价格、单位成本和固定费用影响分别列示，并与经营利润总差异勾稽。

## 阶段三：滚动预测与情景分析

- 保留已发生月份实际值，只预测未来月份。
- 建立基准、乐观和谨慎情景。
- 计算全年预测及年度目标缺口。

状态：核心计算已完成。已实现实际月份锁定、未来月份情景假设和全年情景汇总；年度目标缺口将在管理报告阶段加入。

## 阶段四：管理报告与一键 Demo

- 输出摘要、趋势、事业部、产品、差异桥、预测和数据质量工作表。
- 建立一键运行命令和公开 README。

## 阶段五：验收与求职材料

- 运行完整自动化测试。
- 更新累计版简历。
- 生成 STAR 项目面试手册。
