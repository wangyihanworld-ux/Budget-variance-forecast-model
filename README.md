# 预算差异分析与滚动预测模型

这是一个面向财务 BP 与经营分析场景的 Python 项目。项目将使用完全合成的数据，完成预算执行分析、差异归因、滚动预测、情景分析和 Excel 管理报告。

> 当前状态：项目规划与仓库骨架已建立，核心模型正在开发。

## 业务问题

模型将回答以下问题：

- 收入、毛利和经营利润相对预算发生了什么变化？
- 差异来自销量、价格、产品结构、单位成本还是固定费用？
- 当前趋势延续后，全年结果可能达到多少？
- 距离年度目标还有多大缺口？
- 乐观、基准和谨慎情景下，关键指标如何变化？

## 计划交付

- 完全脱敏的合成数据生成器
- 预算与实际数据校验
- 价格、销量、结构、成本和费用差异归因
- 基准、乐观、谨慎三种滚动预测情景
- 管理层 Excel 报告与一键运行入口
- 自动化测试和可复现 Demo
- 项目完成后的简历更新与 STAR 面试手册

## 核心口径

- 收入 = 销量 × 平均售价
- 毛利 = 收入 − 变动成本
- 经营利润 = 毛利 − 固定费用
- 滚动预测 = 已发生月份实际值 + 剩余月份预测值
- 差异归因合计必须与总差异勾稽，拆分顺序和交互项处理方式必须公开
- 实际月份不得被预测值覆盖
