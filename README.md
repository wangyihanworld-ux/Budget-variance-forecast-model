# 预算差异分析与滚动预测模型

这是一个面向财务 BP 与经营分析场景的 Python 项目。项目将使用完全合成的数据，完成预算执行分析、差异归因、滚动预测、情景分析和 Excel 管理报告。

> 当前状态：合成数据、输入校验、完整利润差异归因和三情景滚动预测已经完成；Excel 管理报告正在开发。

## 业务问题

模型将回答以下问题：

- 收入、毛利和经营利润相对预算发生了什么变化？
- 差异来自销量、价格、产品结构、单位成本还是固定费用？
- 当前趋势延续后，全年结果可能达到多少？
- 距离年度目标还有多大缺口？
- 乐观、基准和谨慎情景下，关键指标如何变化？

## 计划交付

- 完全脱敏的合成数据生成器
- 预算与实际数据校验
- 价格、销量、结构、成本和费用差异归因
- 基准、乐观、谨慎三种滚动预测情景
- 管理层 Excel 报告与一键运行入口
- 自动化测试和可复现 Demo
- 项目完成后的简历更新与 STAR 面试手册

## 核心口径

- 收入 = 销量 × 平均售价
- 毛利 = 收入 − 变动成本
- 经营利润 = 毛利 − 固定费用
- 滚动预测 = 已发生月份实际值 + 剩余月份预测值
- 差异归因合计必须与总差异勾稽，拆分顺序和交互项处理方式必须公开
- 实际月份不得被预测值覆盖

## 当前已实现

- 自动生成 2026 年 12 个月、2 个事业部、4 个虚构产品的预算数据；
- 自动生成前 1—12 个已发生月份的实际数据，默认生成前 6 个月；
- 生成谨慎、基准和乐观三组完全合成的预测假设；
- 校验必要字段、重复主键、负数或非数字以及实际记录缺少预算；
- 计算收入、变动成本、毛利和经营利润的预算差异；
- 将经营利润差异拆分为总销量、产品结构、价格、单位变动成本和固定费用影响；
- 检查各项利润影响是否与经营利润总差异严格勾稽。
- 保留已发生月份实际值，只对未来月份应用谨慎、基准和乐观情景假设；
- 输出各情景的全年收入、成本、毛利和经营利润预测。

收入差异采用固定顺序：先按预算价格计算数量影响，再按实际数量计算价格影响，交互项因此归入价格影响。利润桥先以预算产品结构计算总销量影响，再计算实际结构偏离预算结构的影响。以上顺序会在最终报告中明确披露。
