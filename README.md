# 预算差异分析与滚动预测模型

[![tests](https://github.com/wangyihanworld-ux/Budget-variance-forecast-model/actions/workflows/tests.yml/badge.svg)](https://github.com/wangyihanworld-ux/Budget-variance-forecast-model/actions/workflows/tests.yml)

这是一个面向财务 BP 与经营分析场景的 Python 项目。项目将使用完全合成的数据，完成预算执行分析、差异归因、滚动预测、情景分析和 Excel 管理报告。

> 当前状态：项目已完成。核心模型、三情景滚动预测、一键脱敏 Demo、Excel 管理报告、自动化测试和求职材料均已通过最终验收。

## 业务问题

模型将回答以下问题：

- 收入、毛利和经营利润相对预算发生了什么变化？
- 差异来自销量、价格、产品结构、单位成本还是固定费用？
- 当前趋势延续后，全年结果可能达到多少？
- 距离年度目标还有多大缺口？
- 乐观、基准和谨慎情景下，关键指标如何变化？

## 项目交付

- 完全脱敏的合成数据生成器
- 预算与实际数据校验
- 价格、销量、结构、成本和费用差异归因
- 基准、乐观、谨慎三种滚动预测情景
- 管理层 Excel 报告与一键运行入口
- 自动化测试和可复现 Demo
- 项目完成后的简历更新与 STAR 面试手册

## 核心口径

- 收入 = 销量 × 平均售价
- 毛利 = 收入 − 变动成本
- 经营利润 = 毛利 − 固定费用
- 滚动预测 = 已发生月份实际值 + 剩余月份预测值
- 差异归因合计必须与总差异勾稽，拆分顺序和交互项处理方式必须公开
- 实际月份不得被预测值覆盖

## 当前已实现

- 自动生成 2026 年 12 个月、2 个事业部、4 个虚构产品的预算数据；
- 自动生成前 1—12 个已发生月份的实际数据，默认生成前 6 个月；
- 生成谨慎、基准和乐观三组完全合成的预测假设；
- 校验必要字段、重复主键、负数或非数字以及实际记录缺少预算；
- 标准化 Excel 常见的数字文本和月份日期，并拒绝空表、无效日期与空业务键；
- 计算收入、变动成本、毛利和经营利润的预算差异；
- 将经营利润差异拆分为总销量、产品结构、价格、单位变动成本和固定费用影响；
- 检查各项利润影响是否与经营利润总差异严格勾稽。
- 保留已发生月份实际值，只对未来月份应用谨慎、基准和乐观情景假设；
- 输出各情景的全年收入、成本、毛利和经营利润预测。
- 自动生成独立的合成输入工作簿和包含7张工作表的管理报告；
- 计算年度经营利润目标、目标差额与目标达成率；
- 输出管理摘要、利润差异桥、月度趋势、情景预测、明细和数据质量检查。

收入差异采用固定顺序：先按预算价格计算数量影响，再按实际数量计算价格影响，交互项因此归入价格影响。利润桥先以预算产品结构计算总销量影响，再计算实际结构偏离预算结构的影响。以上顺序会在最终报告中明确披露。

## 运行演示

```powershell
python -m pip install -e .
python -m budget_variance_forecast.demo
```

安装后也可以直接运行等价的命令：

```powershell
budget-forecast-demo
```

指定输出目录：

```powershell
python -m budget_variance_forecast.demo --output-dir .\my_demo_output
```

演示会生成：

- `合成预算与实际输入.xlsx`：预算、实际、三种情景假设和脱敏说明；
- `预算差异与滚动预测管理报告.xlsx`：管理摘要、利润差异桥、月度趋势、滚动预测、预测明细、差异明细和数据质量。

默认演示中，上半年实际收入为 3,043,564.00 元，较预算高 17,584.00 元；实际经营利润为 840,126.64 元，较预算低 10,724.36 元。利润不利差异主要来自单位变动成本，利润桥勾稽差异为 0。基准情景全年经营利润为 1,790,715.64 元，年度预算目标差额为 -10,724.36 元。

运行测试：

```powershell
python -m unittest discover -s tests -v
```

当前共 22 项自动化测试，覆盖输入契约、差异归因、利润桥勾稽、历史实际锁定、情景方向和工作簿可重开等关键规则。

## 数据安全

公开仓库只允许使用合成数据，不提交真实公司名称、预算、财务流水、客户信息、合同价格或经营报告。

## 业务口径与局限

- 预算差异只比较已经发生月份的预算与实际，不用全年预算与半年实际直接比较。
- 收入桥采用“先数量、后价格”的顺序，因此数量与价格的交互项归入价格影响。
- 利润桥先按预算结构计算总销量影响，再将实际产品组合偏离预算组合的部分列为结构影响。
- 年度经营利润目标使用全年预算经营利润，不代表真实公司的正式业绩目标。
- 三种情景仅调整未来月份，已经发生月份保持实际值不变。
- 情景分析是基于设定系数的条件模拟，不是因果推断、统计置信区间或业绩承诺。
